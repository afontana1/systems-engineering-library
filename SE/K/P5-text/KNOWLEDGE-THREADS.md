# Phase 5 — Six interconnected concept pathways

Each thread links SoS engineering, enterprise outcomes and complex-systems judgment. Start at a mission claim and move forward; reverse the chain to study change impact.

## 1. Technical coalition to legitimate capability
Constituent independence (771/W1) → governance agreements (771/W2) → mission thread (771/W3) → interoperability (771/W5) → enterprise authority and legitimacy (753/W2) → critical boundary review (742/W8).

## 2. Evidence to credible action
Data provenance (771/W6) → Bayesian uncertainty (771/W7) → model federation (771/W8) → distributed assurance (771/W10) → enterprise outcome metrics (753/W3) → methodological critique (742/W9).

## 3. Failures to resilient operations
Cascading dependencies (771/W9) → alternate mission paths (771/W11) → external strategic scenarios (753/W9) → enterprise feedback (753/W5) → dynamic risk and safe-to-learn interventions (742/W11).

## 4. Investment to enterprise transformation
Physical constituent allocations (771/W4) → option-aware SoS roadmap (771/W11) → enterprise capabilities (753/W6) → dependent investment portfolio (753/W7) → workforce and supplier transition (753/W8) → target operating model (753/W10).

## 5. From hard optimization to plural learning
Quantified mission constraints (771/W3) → portfolio optimization (753/W7) → Type A hard methods (742/W3) → Type B service process (742/W4) → Type E worldviews (742/W7) → Type F power critique (742/W8).

## 6. Continuous adaptation without losing accountability
Live constituent change (771/W12) → live enterprise funding/authority changes (753/W12) → Explore and Produce (742/W10) → bounded Intervene (742/W11) → Check outcomes, distribution and method fit (742/W12).

## Capstone integration challenge

Trace one changed accessibility requirement across at least 12 nodes involving independent constituent versions, data semantics, enterprise funding and authority, affected riders, evidence and test validity. Inject an unannounced constituent update and a funding shortfall. Write two different defensible decisions for different stakeholder perspectives; then identify what information, authority or safeguard could reconcile them, if reconciliation is possible.
