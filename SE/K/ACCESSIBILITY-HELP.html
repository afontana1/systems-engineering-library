Keyboard and accessibility help

This library is designed for offline reading. The main learning content, textbooks, and labs do not require an account or network connection.

Navigate without a mouse

  • Press Tab and Shift + Tab to move between links and controls.
  • Press Enter to open a link, select a search result, or activate a focused button. Press Space to activate many buttons and checkboxes.
  • Use the Skip to learning content link at the start of a page to bypass repeated navigation.
  • On textbook, lesson, or lab pages, press / when you are not typing to focus the library-wide search field.
  • Select Study list in the shared navigation to open recent and saved resources. Press Escape to close that panel and return focus to its button.
  • Use the visible previous/next navigation controls to move through adjacent learning resources.

Choose the clearest reading format

In the encyclopedia you can read a reference, follow a learning route, or open its original standalone HTML or Markdown. The learning-pathways guide is a simpler static alternative to the interactive pathway reader.

Find and resume material

Search accepts engineering questions, terminology, and abbreviations. Read and save controls can store progress on your device. Storage may be restricted when using file:// links or private browsing; the concept directory explains the limitations. Saved markers indicate self-reported reading, not mastery.

Known limitations

Automated checks do not prove screen-reader compatibility, accessibility conformance, or mathematical notation quality on every page. Some diagrams, notebooks, and complex formula displays may require the Markdown or source alternative. Native extracted-folder navigation should be confirmed on your own browser, because the release-test environment blocks file:// navigation.

Suggested test

Open the concept directory, search for a topic, read it, then return to the concept directory using only the keyboard. If any control has no visible focus indicator or cannot be activated, record the page and control name for future repair.
