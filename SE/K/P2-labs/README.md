# Phase 2 — Shared Workbook and Computation Lab (v17)

These supplementary **fictional** case files connect Books VI, VII and VIII. They are templates for independent practice, not preapproved designs or evidence of deployed performance.

- `python/`: repeatable calculations, unit tests and assumption checks.
- `datasets/`: editable inputs, risks, budgets and claim-to-test evidence ledgers.
- `notebooks/`: five executable teaching exercises with reflection prompts.
- `diagrams/`: three graph models in editable DOT and rendered SVG form.

## Suggested workflow

1. Copy a dataset and note its revision and fictional nature.
2. Make a prediction before running calculations.
3. Run an illustrative calculation, then vary its assumptions.
4. Record the configuration, limits and decision conditions.
5. Return to the original course mastery assignment rather than submitting the template as your work.
