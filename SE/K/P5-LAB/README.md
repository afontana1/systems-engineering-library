# Phase 5 Computational and Critical-Inquiry Laboratory

These are standard-library Python examples, synthetic datasets, and small computational notebooks that accompany Books 18–20. They support reasoning practice, not service certification or claims about real agencies. The models deliberately state simplifying assumptions. Do not use to dispatch vehicles, make medical decisions, or substitute for community consultation.

## Run

```sh
cd SE/K/P5-LAB
python -m unittest -v test_phase5_models.py
```

Open each notebook with Jupyter or another compatible local notebook environment. The notebooks use only the Python standard library and this folder's `phase5_models.py`.

Datasets are invented examples and include deliberately stale revisions, subgroup differences, and unresolved assurance flags. Treat their limitations as part of the exercise.
