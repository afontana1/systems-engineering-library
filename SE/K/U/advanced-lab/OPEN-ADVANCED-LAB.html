Source and reproducibility

Editable materials include the JSON architecture, CSV engineering registers, fault descriptions, Python simulator, test suite, Jupyter notebooks and an independent board decision. Run python -m unittest discover -s tests -v and python -m src.run_advanced from the extracted advanced-lab directory.

Important: all demand, capacities, durations, faults and performance thresholds are invented for teaching. The reference decision is not ready for real-world operations.
