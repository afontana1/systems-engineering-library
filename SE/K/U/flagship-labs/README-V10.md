# v10 executable exercises

Run from this folder with Python 3.10+: `python -m unittest -v test_flagships_v10.py`.

All calculations are synthetic teaching illustrations. Checks confirm arithmetic and basic boundary behavior, **not** external validity, accreditation, regulatory safety, or deployment readiness. Notebook cells can be run using Python 3 + Jupyter, or simply inspected for their plain Python algorithms.

- `architecture_models.py`: series/parallel availability and stale-event state-machine rules.
- `optimization_control.py`: integer fleet enumeration and scalar feedback stability.
- `safety_events.py`: conditional hazard-event trees and direct-loss arithmetic.
- `simulation_credibility.py`: correlation-aware variance, replication intervals and seeded samples.
- `enterprise_portfolio.py`: small resource-constrained portfolios with dependencies and directed-graph reachability.
