# Systems Engineering Knowledge and Learning Atlas

The learning atlas connects **80 canonical concept references**, **20 graduate-level textbooks**, guided routes, course guides and existing labs.

## Find the right resource

- [Open the encyclopedia](U/OPEN-ENCYCLOPEDIA.html) to search concepts, questions and the entire indexed collection.
- [Browse the concept index](CONCEPT-ENCYCLOPEDIA.html) for A–Z reference entries.
- [Follow a learning pathway](LEARNING-PATHWAYS.html) for a recommended beginner-to-advanced order.
- [Complete a learner journey](LEARNER-JOURNEYS.html) to connect theory, a chapter and existing practice.
- [Read a textbook](OPEN-BOOKS.html) or [find a lab](LAB-LIBRARY.html).
- [Visit the concept directory](CONCEPTS.html) for concept references.

The [library homepage](../../index.html) provides a guided starting point. The [offline reading guide](OFFLINE-HELP.html) explains extracting the library, bookmarks, offline navigation, and reading accessibility.

The library's instructional scenarios are illustrative. Technical claims should always be evaluated against the evidence and assumptions given in the relevant article.
