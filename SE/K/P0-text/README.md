## Recommended study pattern

1. **Concepts (60–90 minutes):** Read the companion lesson, reproduce the example and write a three-sentence explanation from memory.
2. **Source check (45–120 minutes):** Follow the tagged NASA, SEBoK or GAO source, comparing the assumptions and precise definitions.
3. **Application (2–5 hours):** Complete the original guide's artifact, not merely the short practice questions here.
4. **Challenge (30–60 minutes):** Attempt the three practice questions before revealing explanations; invent an off-nominal scenario and identify which requirement or management decision it affects.
5. **Evidence (30 minutes):** Version the artifact, link source assumptions, and record unresolved questions. Repeat later if retrieval is weak.

**Important:** The original guides already contain extensive 12-week lesson units and grading rubrics. This companion deliberately adds a second conceptual perspective and small worked cases instead of replacing those course units. Some mastery needs original cited reading, model-building, independent review, and more difficult assignments.
