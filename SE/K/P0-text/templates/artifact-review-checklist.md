# Artifact evidence review checklist

- [ ] Purpose and accountable stakeholder are stated.
- [ ] All assumptions, scope boundaries, versions and units are explicit.
- [ ] Requirements/needs connect to an actual operational scenario.
- [ ] Interfaces and failure responses are owned.
- [ ] All calculations can be reproduced independently.
- [ ] Critical decisions are made by delegated authority.
- [ ] Cost/schedule effects of technical changes are linked.
- [ ] Verification evidence uses the configured item and current baseline.
- [ ] Validation and acceptance are not confused with verification.
- [ ] Unresolved high-consequence items limit the proposed authorization.
- [ ] Changes and review findings have owners, due dates and closure rules.
