## Conceptual explanation

### Separate planned work, completed work and cost paid
Earned Value Management (EVM) distinguishes **Planned Value (PV)**, budgeted value of work scheduled; **Earned Value (EV)**, budgeted value of actual work accomplished; and **Actual Cost (AC)**, what that work cost. These are all monetary quantities but answer different questions. A project that spends 80% of budget is not necessarily 80% complete. Earned progress requires objective completion evidence linked to WBS work packages.

Define **CV = EV − AC**, **SV = EV − PV**, **CPI = EV/AC**, **SPI = EV/PV**, when denominators are nonzero. Negative CV indicates cost overrun relative to earned work; negative SV indicates less budgeted work accomplished than planned at the status date. SPI is **not** a direct measure of days late; it can become misleading late in a project as nearly all work is earned.

### Forecasting with explicit assumptions
A basic EAC extrapolation assumes future CPI resembles past CPI: **EAC = AC + (BAC − EV)/CPI**. If the remaining work is fundamentally different, build a bottom-up estimate-to-complete and use **EAC = AC + ETC** instead. EAC forecasts should reconcile known technical scope changes, discrete supplier quotes, resource productivity, schedule impacts and uncertainty. **VAC = BAC − EAC** reveals the forecast variance at completion.

For performance required to hit a target budget, **TCPI(BAC) = (BAC − EV)/(BAC − AC)**, if the denominator is positive. An implausibly high TCPI is an alert that the original target may be unrealistic. Never respond by manipulating earned percent complete.

### Variance narratives
A useful report states root causes and actions, not just red indices: 'The integration package earned $40k versus $60k planned, with $55k spent because interface rework consumed test staff. The corrective action is to freeze ICD version and rerun contract tests; cost-to-complete has increased.' Tie the analysis to updated evidence and current risks.

## Worked example: reason through the case

**Worked numbers:** BAC=$500k; PV=$250k; EV=$200k; AC=$240k. CV=−$40k; SV=−$50k; CPI=0.8333; SPI=0.8. If future work matches cumulative CPI, EAC=240+300/0.8333≈**$600k**; VAC≈−$100k. TCPI to hit original BAC is (500−200)/(500−240)=**1.154**, meaning remaining work must be earned at a CPI of about 1.154—far better than current 0.833. This is a management challenge, not an automatic impossibility.

## A failure mode to recognize

Mistake: reporting percent spent as percent complete, or treating the CPI extrapolation as a fact without assumptions.
