Scope and limits

This is first-pass weekly-topic coverage, not an exhaustive graduate-level textbook, accreditation, or a replacement for original course mastery assessments. It includes authored teaching notes, a worked case for each topic, guided checks adapted from the original user-provided course guides, and substantive cross-course tutorials. Mathematical and simulation examples simplify real mechanisms. The tool tests verify elementary calculations, not model validity. Additional original-source readings, expert review, real-world data and independent verification are necessary for high-consequence use. Website lesson text is self-contained; linked external references require internet.
