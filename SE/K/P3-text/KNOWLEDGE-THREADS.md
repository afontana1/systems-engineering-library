# Phase 3 knowledge threads (cross-course)

The six courses build one analysis decision chain, not six disconnected software demonstrations.

1. **Scenarios → stochastic inputs → risk:** [MBSE analytics](lessons/645-632-w02.md) → [distribution modeling](lessons/645-756-w02.md) → [simulation input modeling](lessons/645-757-w03.md) → [uncertainty and dependence](deep-dives/uncertainty-and-dependence.md).
2. **Functional architecture → event logic → evidence:** [MBSE behaviors](lessons/645-632-w04.md) → [DES](lessons/645-757-w05.md) → [verification and credibility](deep-dives/simulation-credibility.md).
3. **Parameter equations → physics → numerical credibility:** [parametric MBSE](lessons/645-632-w08.md) → [ODE derivation](lessons/645-758-w02.md) → [numerical solver tutorial](deep-dives/numerical-dynamics.md).
4. **Experiments → response surfaces → optimal design:** [DOE](lessons/645-756-w05.md) → [surrogates](lessons/645-784-w10.md) → [model-selection and error](deep-dives/model-selection-and-surrogates.md).
5. **Feedback → operations → investment policy:** [stocks and flows](lessons/645-781-w05.md) → [fleet sustainment](lessons/645-756-w11.md) → [value of information](deep-dives/value-of-information.md).
6. **Trade space → preference → uncertainty:** [model-linked trade study](lessons/645-632-w09.md) → [Pareto analysis](lessons/645-784-w04.md) → [decision gates](deep-dives/pareto-and-values.md).
7. **Baseline → model credibility → governing action:** [MBSE baseline](lessons/645-632-w12.md) → [simulation credibility](lessons/645-757-w11.md) → [conditional design recommendation](deep-dives/from-model-to-decision.md).
