# Receive the baseline, define intended use, and tailor the MBSE method and modeling plan

## The idea in context

A model has an intended decision, not just an intended audience. Begin by specifying the decision, authorized baseline, model boundary, permitted notation, ownership and change control. Separate requirements that the model must represent from questions the model must answer. A modeling plan should define viewpoints, element identifiers, naming rules, validation queries, evidence links and exit criteria. Completeness is meaningful only relative to those declared questions; a dense diagram can still fail to expose a critical missing interface.

## Worked reasoning: apply it to the shuttle case

The campus shuttle model will support a fleet-sizing decision. Its scope includes demand, dispatch logic, vehicle capacity and charging constraints, but not detailed tire dynamics. A decision query asks whether all proposed fleets meet a 12-minute service threshold in each approved scenario. The excluded dynamics need an assumption and escalation condition.

**Assumption to challenge:** Confusing a tool-created diagram with an authoritative, versioned system model. Record what observation or test would expose this failure before using the result in a decision.

## Test understanding before reading the answers

The next three questions are adapted from the **original guide's Week 1 knowledge check**, with its answer guidance retained so you can learn and self-check in one place.

1. What is intended use?
2. What is a derived view?
3. Why tailor OOSEM?

<details><summary><strong>Reveal guided answers</strong></summary>

1. **What is intended use?** The bounded decision, claim, review, or activity for which a model and its evidence are judged adequate.

2. **What is a derived view?** A presentation generated from authoritative model content; it should not become an uncontrolled competing source.

3. **Why tailor OOSEM?** Projects differ in decisions, lifecycle, risk, organization, and available evidence; tailoring preserves required reasoning while avoiding ritual work.

</details>
