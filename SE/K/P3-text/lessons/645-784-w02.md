# Translate stakeholder values into objectives, measures, and value structure

## The idea in context

Objectives describe what stakeholders value; measures operationalize those objectives; value functions map outcomes to preference. Fundamental objectives differ from means objectives. Good value structure avoids double counting correlated measures such as wait time and punctuality when they describe overlapping benefit. Check units, direction of preference, scaling and stakeholder disagreements.

## Worked reasoning: apply it to the shuttle case

A value function gives 0 for a 20-minute pickup wait and 1 for a 5-minute wait. An observed 10-minute wait maps to 2/3 under linear interpolation, but stakeholders might prefer a nonlinear penalty above 12 minutes.

**Assumption to challenge:** Treating normalized raw measurements as utility without eliciting their preference meaning. Record what observation or test would expose this failure before using the result in a decision.

## Test understanding before reading the answers

The next three questions are adapted from the **original guide's Week 2 knowledge check**, with its answer guidance retained so you can learn and self-check in one place.

1. What is a means objective?
2. What is an attribute?
3. Why use a nonlinear value function?

<details><summary><strong>Reveal guided answers</strong></summary>

1. **What is a means objective?** An objective valued because it contributes to another, more fundamental objective.

2. **What is an attribute?** A scale used to measure achievement of an objective.

3. **Why use a nonlinear value function?** To represent preference that changes nonlinearly over the performance range.

</details>
