The idea in context

Multiattribute value methods aggregate preferences under assumptions about independence and trade-offs. Weights must reflect swing significance over defined ranges, not abstract importance labels. Sensitivity reveals where rankings change. Expected utility may require nonlinear risk attitude, while simple additive value usually assumes preferential structure; distinguish both.

Worked reasoning: apply it to the shuttle case

A 0.2 change in service value matters only relative to the defined scale. If cost weight rises from 0.3 to 0.6, a cheaper design may overtake a faster one. Record the crossover and negotiate its relevance rather than declaring one universal winner.

Assumption to challenge: Assigning subjective weights without clear attribute ranges and then treating scores as physical measurements. Record what observation or test would expose this failure before using the result in a decision.

Test understanding before reading the answers

The next three questions are adapted from the original guide's Week 5 knowledge check, with its answer guidance retained so you can learn and self-check in one place.

  1. What is a swing weight?
  2. What is compensability?
  3. What is a break-even analysis?

<details><summary><strong>Reveal guided answers</strong></summary>

  1. What is a swing weight? The relative value of moving an attribute across its specified worst-to-best range.

  2. What is compensability? The assumption that poor performance on one objective can be offset by better performance on another.

  3. What is a break-even analysis? Finding the parameter or preference value at which the recommended alternative changes.

</details>
