## The idea in context

Federation and co-simulation combine models with possibly different solvers and clocks. FMI defines portable model interfaces; HLA is a federation interoperability framework. Specify time advancement, event causality, data ownership, interpolation, synchronization and failure recovery. Error may arise from communication step size even when each component solver is accurate. LVC integration additionally raises real-time and representativeness constraints.

## Worked reasoning: apply it to the shuttle case

A vehicle dynamics component updates every 1 ms and the dispatch component every 1 s. A controller that sees stale obstacle state can violate an assumed response bound. Handshake timing and interpolation must be part of the interface contract.

**Assumption to challenge:** Believing an FMI-compatible archive or successful network connection proves valid coupled behavior. Record what observation or test would expose this failure before using the result in a decision.

2. **What are FMI’s principal modes?** Model Exchange, Co-Simulation, and Scheduled Execution.

3. **What is composability?** The ability of model components to combine while preserving valid assumptions and behavior for the intended use.
