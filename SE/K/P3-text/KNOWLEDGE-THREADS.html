Phase 3 knowledge threads (cross-course)

The six courses build one analysis decision chain, not six disconnected software demonstrations.

  1. Scenarios → stochastic inputs → risk: MBSE analytics → distribution modeling → simulation input modeling → uncertainty and dependence.
  2. Functional architecture → event logic → evidence: MBSE behaviors → DES → verification and credibility.
  3. Parameter equations → physics → numerical credibility: parametric MBSE → ODE derivation → numerical solver tutorial.
  4. Experiments → response surfaces → optimal design: DOE → surrogates → model-selection and error.
  5. Feedback → operations → investment policy: stocks and flows → fleet sustainment → value of information.
  6. Trade space → preference → uncertainty: model-linked trade study → Pareto analysis → decision gates.
  7. Baseline → model credibility → governing action: MBSE baseline → simulation credibility → conditional design recommendation.
