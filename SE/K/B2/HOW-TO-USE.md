# Read Volume II alongside the Management of Systems Projects course

The [weekly course guide](../../C/P0/EN645667.md) assigns independent work and defines mastery; these [twelve chapters](README.md) teach the concepts, while the corresponding twelve hypothetical laboratories let you rehearse decisions. Start the local website at [OPEN-BOOK.html](OPEN-BOOK.html).

## Computational practice

Run `python -m unittest discover -s tools -p "test*.py"` from this directory, or run the notebooks from the `notebooks/` directory with Python 3 and a Jupyter installation. The `tools/project_math.py` example is intentionally small and uses no extra runtime packages.

All quantities, roles, pricing conventions, acceptance criteria and outcomes in the examples are fictional. Models and checklists cannot replace appropriate project, legal, contractual, or safety review.
