Open the library

  1. Extract the complete archive to a folder. Do not browse the ZIP directly.
  2. Open SE/START-HERE.html in your browser.
  3. Use Search, Learning pathways or Textbooks to begin. Links should open pages in the same extracted folder.

Save your place

The study desk uses local browser storage when the browser allows it. Saved and studied markers do not transfer between browsers, devices, private windows or changed file locations. If the study list is unavailable, you can still read every page and keep bookmarks in your browser.

If a link does not open

Verify that the whole archive was extracted, then return to the library homepage. Some browsers restrict storage or script behavior for local files. The downloadable library does not require a web server to hold the instructional content, but interactive functions may vary by browser.

Reading accessibility

Use Tab to move between controls, Enter to activate a link, and the slash key to focus search where supported. Open the keyboard and accessibility guide for more.

External reference links require internet access; the core textbooks, references and labs are included locally.
