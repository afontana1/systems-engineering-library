# Reading and Study Help

1. Extract the complete library archive into a folder. Do not run pages inside the ZIP.
2. Open `SE/START-HERE.html` in your browser.
3. Choose Search, Guided learning, Textbooks or Labs.
4. To resume, open [My study desk](STUDY-DESK.html) or use browser bookmarks.

Study markers are stored in the browser when permitted. They may not transfer between browsers, devices, private windows or different file locations. Core educational content is included in the extracted library, while selected external references require internet access.

For navigation help, see [Keyboard and accessibility help](ACCESSIBILITY-HELP.html).
