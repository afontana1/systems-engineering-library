Knowledge lenses for this course

  • Verification, validation, and acceptance — Verification asks whether the system or element meets specified requirements; validation asks whether it satisfies intended use and stakeholder needs.
  • Verification cross-reference matrices and test design — A verification cross-reference matrix (VCRM) links each controlled requirement to verification method, level, procedure, success criterion, configuration and evidence.
  • Integration build-up and readiness evidence — Integration is the progressive assembly of elements into a functioning system while checking their interactions.
  • Simulation verification, validation, and credibility — Simulation verification asks whether the implementation represents the conceptual model correctly; simulation validation asks whether that model adequately represents reality for its intended use.
  • Probability, distributions, and dependence — An uncertain quantity is not defined by its mean alone.
  • Risk, issue, uncertainty, and opportunity — A risk is an uncertain future event or condition that could affect objectives; an issue is a condition already present that requires action.
