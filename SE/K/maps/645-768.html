Knowledge lenses for this course

  • Functional, logical, and physical architectures — Functional architecture describes what transformations and behaviors must occur, independent of which hardware or software will perform them.
  • Allocation, coverage, and design responsibility — Allocation connects obligations and functions to design elements that will fulfill them.
  • Interface control and integration contracts — An interface control definition specifies what crosses a system-element boundary and under what rules.
  • Integration build-up and readiness evidence — Integration is the progressive assembly of elements into a functioning system while checking their interactions.
  • Verification cross-reference matrices and test design — A verification cross-reference matrix (VCRM) links each controlled requirement to verification method, level, procedure, success criterion, configuration and evidence.
  • Work breakdown structures and technical baselines — A work breakdown structure (WBS) decomposes total project scope into manageable, deliverable-oriented work packages.
