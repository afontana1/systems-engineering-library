# Companion map: EN.645.768 — System Design & Integration

**Phase:** 2 — Concept, design, integration and test  
**Original learning guide:** [phase-2/en-645-768-system-design-and-integration.md](../../C/P2/EN645768.md)

## Knowledge lenses for this course

- [Functional, logical, and physical architectures](../encyclopedia/functional-vs-physical.md) — Functional architecture describes what transformations and behaviors must occur, independent of which hardware or software will perform them.
- [Allocation, coverage, and design responsibility](../encyclopedia/allocation-matrix.md) — Allocation connects obligations and functions to design elements that will fulfill them.
- [Interface control and integration contracts](../encyclopedia/interface-control.md) — An interface control definition specifies what crosses a system-element boundary and under what rules.
- [Integration build-up and readiness evidence](../encyclopedia/integration-strategy.md) — Integration is the progressive assembly of elements into a functioning system while checking their interactions.
- [Verification cross-reference matrices and test design](../encyclopedia/verification-matrix.md) — A verification cross-reference matrix (VCRM) links each controlled requirement to verification method, level, procedure, success criterion, configuration and evidence.
- [Work breakdown structures and technical baselines](../encyclopedia/wbs-and-baselines.md) — A work breakdown structure (WBS) decomposes total project scope into manageable, deliverable-oriented work packages.

## Best supporting shelf for this course
