# Companion map: EN.645.769 — System Test & Evaluation

**Phase:** 2 — Concept, design, integration and test  
**Original learning guide:** [phase-2/en-645-769-system-test-and-evaluation.md](../../C/P2/EN645769.md)

## Knowledge lenses for this course

- [Verification, validation, and acceptance](../encyclopedia/v-and-v.md) — Verification asks whether the system or element meets specified requirements; validation asks whether it satisfies intended use and stakeholder needs.
- [Verification cross-reference matrices and test design](../encyclopedia/verification-matrix.md) — A verification cross-reference matrix (VCRM) links each controlled requirement to verification method, level, procedure, success criterion, configuration and evidence.
- [Integration build-up and readiness evidence](../encyclopedia/integration-strategy.md) — Integration is the progressive assembly of elements into a functioning system while checking their interactions.
- [Simulation verification, validation, and credibility](../encyclopedia/model-vv-and-credibility.md) — Simulation verification asks whether the implementation represents the conceptual model correctly; simulation validation asks whether that model adequately represents reality for its intended use.
- [Probability, distributions, and dependence](../encyclopedia/probability-and-dependence.md) — An uncertain quantity is not defined by its mean alone.
- [Risk, issue, uncertainty, and opportunity](../encyclopedia/risk-vs-issue.md) — A risk is an uncertain future event or condition that could affect objectives; an issue is a condition already present that requires action.
