## How to use each weekly chapter

1. Read the course's original Week N to learn the required deliverable and rubric.
2. Read the corresponding companion chapter's conceptual tutorial and walk the numeric/case example.
3. Answer the three retrieval questions **before** opening the explanations.
4. Perform the smaller transfer exercise and then the full original guide's project.
5. Follow one deep-dive or concept pathway when an idea crosses courses.
6. Record new assumptions, their tests and evidence in the provided worksheets.

## Scope and limits

This is a **full weekly-topic coverage first-pass companion**, not an exhaustive accredited graduate textbook or substitute for original course assessments. Equations and models make their assumptions explicit; synthetic data and results are not field safety or readiness evidence. There are no real autonomous vehicle instructions or operating authorizations. External references remain necessary for some advanced subjects, standards and current domain practice. The Python labs intentionally prioritize transparency over validated simulation fidelity. The website renders content offline; external reference links still need internet.
