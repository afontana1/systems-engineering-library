# Phase 4 connected knowledge pathways

Each pathway crosses course boundaries. Work from the leftmost claim to the rightmost evidence; reverse the arrows to study change impact.

## 1. A change becomes an authorized mission response

Stimulus → agility response requirement (780/W1) → uncertainty and tailored lifecycle (780/W2) → learning interval (780/W5) → evidence-aware increment (780/W9) → digital thread / configuration (782/W8) → mission-level effectiveness (782/W10–11) → measured process improvement (783/W9–10).

## 2. Bottlenecks become measurable improvement hypotheses

Value stream and WIP (780/W3) → throughput and aging (780/W6) → event log (783/W4) → valid process baseline (783/W5) → root-cause challenge (783/W6) → queuing simulation (783/W7) → pilot (783/W9) → reaction plan (783/W10).

## 3. Architecture determines option value

Agile tailoring (780/W2) → modular interface (780/W7) → model semantics and queries (782/W4–6) → versioned thread (782/W8) → design alternatives (782/W11) → process redesign (783/W8).

## 4. Credibility and trust span simulation, twins and assurance

Continuous verification (780/W9) → evidence provenance (780/W10) → M&S validity (782/W3) → source authority (782/W7) → twin state and security (782/W9) → mission decision (782/W12) → control and containment (783/W10).

## 5. Local autonomy remains bounded by enterprise accountability

Decision rights (780/W4) → scaled supplier interfaces (780/W11) → ASOT governance (782/W7) → mission owner (782/W10) → process ownership (783/W2–3) → red-team challenge (783/W11).

## 6. Evidence closure is a graph, not a checklist

Requirement → design and interface → configured implementation → test conditions and result → observed operation → mission claim → accountable release decision. Every connection needs type, owner, version and applicability. An absent or stale edge can invalidate the final claim.

## Practice

Choose one Northstar decision. Map at least 12 nodes and links, then introduce one stale model result, one missing hazard-control test and one changed mission assumption. Which changes propagate to the release decision? What can remain approved?
