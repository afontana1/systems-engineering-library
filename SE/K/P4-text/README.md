### How to use each week

1. Open the original Week N lesson for full required study, assignment, rubric and mastery gate.
2. Work through the matching companion chapter without revealing the answers.
3. Read the related concept essay, run a small calculation or graph check, and modify its assumptions.
4. Complete the guide assignment using the CSV worksheets as starting points; preserve controlled evidence and reviewer questions.
5. Record what you still cannot explain or reproduce; update the artifact rather than merely ticking a completion box.

This is an original independent study companion, not Johns Hopkins course material, academic credit, or certified safety guidance. All case numbers are hypothetical, and model assumptions are explicitly bounded.
