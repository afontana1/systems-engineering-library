# Manual Windows acceptance checklist (not yet executed)

These checks require a real Windows computer; the automated publishing environment could not run native file navigation.

1. Extract the complete `Systems-Engineering-Library.zip` to a local folder.
2. In a current Chrome or Edge browser, open `SE/START-HERE.html` using File > Open. Verify the homepage is readable without a web server.
3. Select a guided learning route, open a concept reference, follow a textbook recommendation, and open the linked existing lab. Verify each step opens the intended resource.
4. Search for “How do I prove my design is safe?” and confirm that system safety, verification and assurance resources appear. Open a result and return to the same search.
5. Open a textbook chapter, mark it studied and save it. Open the study desk and check both markers; close/reopen the browser and verify the marks persist. If storage is blocked, note the browser/version and whether bookmarks still function.
6. Test keyboard-only navigation: Tab, Shift+Tab, Enter, Escape to close the study drawer and the slash shortcut where offered. Check focus is visibly indicated.
7. Resize to a narrow window and confirm no horizontal overflow on the homepage, encyclopedia, chapter, lab and study desk.
8. Repeat the main learning route in another browser, if available. Screen-reader users should test headings and controls with NVDA or other assistive technology.
9. Record device, Windows version, browser version, results, unexpected behavior and a screenshot or affected page path for any failures.

Do not report full native offline compatibility or screen-reader conformance until these checks have actually been completed.
